Game_of_Life

System Guide: Click and drag on the grid to draw live cells.

Rules of Survival:
1. Underpopulation: Cell dies if < 2 neighbors.
2. Survival: Cell lives if 2 or 3 neighbors.
3. Overpopulation: Cell dies if > 3 neighbors.
4. Reproduction: Dead cell revives if exactly 3 neighbors.
